# Phase 1: Cl(4,1) 几何代数数学验证

## 目标

验证 Clifford 代数 Cl(4,1) 的基础运算在 float32 工程实现中是否正确：grade-0 不变性、等变性、多通道独立性、Eraser 安全性、梯度流健康度。

## 实验设计

10 个单元测试，覆盖：
1. 乘法表正确性（e1-e4² = +1, e5² = -1, 反交换律）
2. 旋转子验证（R·R_rev = 1, 无奇数 grade）
3. Grade-0 不变性（100次 sandwich 积变换）
4. Grade-5 不变性
5. Grade-1 等变性（两种计算方式一致）
6. 梯度流（10层链梯度比）
7. 多通道独立性（8通道 grade-0 不耦合）
8. Eraser 衰减收敛性
9. 不变核不受 Eraser 影响
10. 衰减率梯度健康

## 操作步骤

pip install torch numpy
python phase1/scripts/test_phase1.py

## 结论

Cl(4,1) 几何代数的数学性质在 float32 工程实现中完全成立。Grade-0 不变性误差仅 10⁻⁶ 级别，多通道间零泄漏，Eraser 操作后 grade-0 变化精确为零。数学基础可靠，可进入后续实验。

关键踩坑：
- e5² = -1（负度规）导致 sandwich 积不保欧几里得范数 → 对每个 grade 分别归一化
- exp(B) Taylor 展开需 16 项（12项精度不够）
